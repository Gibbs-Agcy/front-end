# Gibbs Agency

Modern web çözümleri ve dijital deneyimler sunan Next.js 16 tabanlı ajans web sitesi.

## 🚀 Özellikler

- ⚡ Next.js 16 (App Router)
- 🎨 Tailwind CSS 3.4
- 📘 TypeScript 5.x (Strict Mode)
- ✨ GSAP animasyonları
- 🎭 Framer Motion desteği
- 📱 Responsive tasarım
- 🌙 Dark mode desteği
- 🎯 Smooth scroll (Lenis)
- 🖱️ Custom cursor
- 📊 Scroll progress indicator

## 📋 Gereksinimler

- Node.js 18+
- npm veya yarn

## 🛠️ Kurulum

1. Bağımlılıkları yükleyin:

```bash
npm install
```

2. Geliştirme sunucusunu başlatın:

```bash
npm run dev
```

3. Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresini açın.

## 📁 Proje Yapısı

```
gibbs-agency/
├── app/
│   ├── (routes)/          # Route grupları
│   ├── components/        # React componentleri
│   ├── hooks/            # Custom hooks
│   ├── lib/              # Utility fonksiyonları
│   └── styles/           # Global stiller
├── public/               # Statik dosyalar
└── ...config files
```

## 🎨 Stil Yapılandırması

Proje Tailwind CSS kullanmaktadır. Renkler ve animasyonlar `tailwind.config.ts` dosyasında tanımlanmıştır.

### Renkler

- **Primary**: #FF6B6B (Vibrant Red)
- **Secondary**: #4ECDC4 (Turquoise)
- **Accent**: #FFE66D (Yellow)
- **Dark**: #0F0F0F
- **Light**: #F7F7F7

## 📦 Scripts

- `npm run dev` - Geliştirme sunucusunu başlatır
- `npm run build` - Production build oluşturur
- `npm run start` - Production sunucusunu başlatır
- `npm run lint` - ESLint kontrolü yapar
- `npm run type-check` - TypeScript tip kontrolü yapar

## 🔧 Yapılandırma

### Environment Variables

`.env.local` dosyası oluşturun ve gerekli değişkenleri ekleyin:

```env
# Örnek environment variables
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```
